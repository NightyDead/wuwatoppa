# 桌宠助手 · WuwaToppa

适用于 Windows 的 **Wuwa Tappo** 桌宠助手，提供 F15 连点、宝箱自动领取和顺序运行计划。当前版本为 **1.1.3**，版本号可在窗口底部查看。

## 快速开始

### 运行打包版

1. 从 [Releases](https://github.com/NightyDead/wuwatoppa/releases) 下载已发布的 Windows ZIP。没有发行包时，可以按下文从源码运行或自行打包。
2. 解压到有写入权限的目录，双击 **桌宠助手.exe**，确认 Windows 的管理员权限提示。请将 EXE 和 `_internal` 文件夹放在一起。
3. 打开 Wuwa Tappo，再按需启动连点或宝箱监测。

### 从源码运行

在 Windows 的 PowerShell 中进入项目根目录，用 Python 创建虚拟环境并安装依赖。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install PySide6-Essentials==6.8.3 pillow numpy
.\.venv\Scripts\python.exe .\程序\launcher.py
```

桌宠以管理员权限运行时，请在管理员 PowerShell 中执行启动命令，确保助手能向桌宠发送鼠标和键盘输入。

## 功能与用法

| 功能 | 怎么用 |
| --- | --- |
| **连点器** | 填写操作次数、操作间隔和运行时长，点「开始连点」。次数和时长都填时先到先停，至少设一项。连点通过 F15 发送操作。 |
| **自动领取** | 填写运行时长（小时）和检查间隔（分钟），点「开始监测」。首次搜索优先截取桌宠主窗口所在屏幕，定位后只复查宝箱附近。成功领取后，从本轮最后一次成功点击完成时计算下一轮。 |
| **间隙连点** | 在「自动领取 → 高级设置」填写间隙连点次数和间隔，每轮领取结束后发送这批按键。开启间隙连点时，只启动监测即可。 |
| **运行计划** | 用「添加连点」或「添加领取」建立步骤，点「执行计划」。步骤按顺序运行，当前步骤被手动停止或异常退出时，计划结束。 |
| **领取记录** | 查看最近 20 次监测的宝箱数量、开始及结束时间和运行状态。 |
| **外观设置** | 调整主题、颜色、壁纸、字体和透明度，点「保存外观」保留下次使用。点「另存为主题」可保存一套可随时切换的外观。 |

按 **Ctrl + Alt** 或点击「全部停止」可停止正在运行的任务。识别有问题时，可从「工具」打开**识别预览（不点击）**或「检查运行环境」。识别预览只截桌宠所在的屏幕。

## 分享主题与升级迁移

- **分享主题**。在「工具 → 分享主题」选当前已保存外观或已有主题，导出带壁纸和自定义字体的 ZIP。接收方通过「导入主题或设置」导入，再到「外观设置」应用。
- **备份设置**。在「工具 → 导出完整设置」备份连点和领取参数、运行计划、当前外观及全部主题。导入完整设置前会提示确认。
- **从旧版升级**。退出旧程序并备份整个文件夹，再将新版文件合并覆盖到原目录，可保留设置、主题和领取记录。两个版本分开安装时，可从新版导入旧版原目录里的 `_internal\设置.json`。源码版的设置位于 `程序\设置.json`。主题相关文件请留在旧版设置原目录中，以便导入时一起迁移。

## 构建 Windows EXE

使用上面创建的虚拟环境，在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe -m pip install pyinstaller
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm --clean .\桌宠助手.spec
```

生成的文件夹版位于 `dist\桌宠助手`。分发时压缩整个文件夹，用户解压后可直接运行。

更多参数、权限和故障排查说明见 [使用说明](使用说明.txt)。
